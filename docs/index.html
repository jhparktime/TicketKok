WHY COUPONCOK

혜택은 많은데,
결제 직전의 판단은 어렵습니다.

쿠폰과 멤버십, 카드 조건이 여러 앱과 문서에 흩어져 있어 사용자는 실제 매장 앞에서 가장 유리한 선택을 놓치기 쉽습니다.

01

흩어진 쿠폰

갤러리·메신저·브랜드 앱에 보관된 쿠폰을 결제 전에 찾기 어렵습니다.

02

복잡한 적용 조건

최소 주문금액, 최대 할인, 등급, 전월 실적, 중복 여부를 직접 비교해야 합니다.

03

신뢰할 수 없는 추천

근거와 계산이 분리되지 않으면 사용자는 AI의 할인 금액을 믿기 어렵습니다.

CONTEXT → EVIDENCE → DECISION

찾고, 확인하고, 계산하고,
선택은 사용자가 합니다.

01▣

기기 안에서 쿠폰 등록

02⌖

주변 지원 매장 식별

Core Location, MapKit, 공공 상가(상권)정보를 결합해 대한민국 내 지원 프랜차이즈 후보를 좁힙니다.

03✦

근거 기반으로 비교

공식 혜택 RAG와 Calculator Tool이 적용 가능한 후보만 비교하고, Agent는 설명과 근거 흐름을 담당합니다.

04✓

사용자가 최종 확인

쿠폰콕은 결제를 실행하지 않습니다. 사용자가 바코드를 열고 결제 완료·사용 처리를 직접 선택합니다.

EXPLAINABLE BY DESIGN

AI가 판단을
대신하는 것이 아니라,
근거를 연결합니다.

Store, Coupon, Benefit, Personalization, Recommendation Agent가 매장 맥락, 쿠폰 후보, 공식 혜택, 동의된 사용 패턴, 설명 생성을 분담합니다. 할인 금액과 순위는 LLM이 아니라 결정론적 Calculator Tool만 확정합니다.

Store→Coupon→Benefit→Personalization→Recommendation

PRIVATE · VERIFIABLE · REVERSIBLE

기기 안에 남깁니다.
